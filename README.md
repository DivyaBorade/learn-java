# Learn Java

Learn and practice basic to advance Java.

## Overview

This repository is a comprehensive resource for learning Java programming, from beginner fundamentals to advanced concepts. Whether you're just starting your Java journey or looking to deepen your expertise, you'll find practical examples, exercises, and projects here.

## Repository Contents

This repository contains:
- **Java Code**: Core Java examples and exercises (8.9%)
- **Supporting Materials**: Additional learning resources and utilities (91.1%)

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher
- A code editor or IDE (IntelliJ IDEA, Eclipse, VS Code, etc.)
- Git (for cloning the repository)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/DivyaBorade/learn-java.git
cd learn-java
```

2. Explore the contents and run the Java programs according to the directory structure.

## Topics Covered

This repository covers Java topics including but not limited to:

- **Basics**: Variables, data types, operators, control flow
- **Object-Oriented Programming**: Classes, objects, inheritance, polymorphism, encapsulation, abstraction
- **Collections**: Arrays, Lists, Sets, Maps, Iterators
- **Exception Handling**: Try-catch, throws, custom exceptions
- **File I/O**: Reading and writing files
- **Multithreading**: Threads, synchronization, concurrent programming
- **Advanced Concepts**: Generics, annotations, reflection, lambda expressions, streams

## How to Use

1. Navigate to relevant topic folders
2. Review the example code with comments
3. Run the programs in your IDE or command line
4. Practice by modifying the examples and creating variations
5. Complete the exercises provided

### Running Java Programs

To compile and run a Java program:

```bash
javac FileName.java
java FileName
```
